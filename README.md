# Prince Renovations | Growth Command Center

A custom, mobile-friendly sales and follow-up CRM preview built by Ignite Co for Prince Renovations (Ontario).

This is a presentation demo, not an operational customer database. All sample leads, pipeline amounts, appointment dates, activity events, and AI messages are illustrative, not claims about Prince Renovations' actual performance.

## Preview goals

- Show where inquiries come from and whether each becomes a consultation, estimate, or signed project.
- Make AI-driven speed-to-lead and ongoing follow-up the centerpiece.
- Surface only genuine human exceptions or owner decisions.
- Give a simple view of upcoming consultations, on-site estimates, quotes, and projected revenue.
- Show planned connections for website forms, Google Business Profile, Twilio SMS, email, calendar, and AI phone assistant.
- Support interactive demo actions with browser-only localStorage. Demo actions do not send email, texts, or calls, create real bookings, or modify a backend.

## Tech
React 18 + Vite + Lucide React. No production backend or credentials are included.

`npm install && npm run dev` to run locally.
`npm run build` to build for Vercel.

**Important**: Connect a secure workspace with authentication and permissions, verified event ingestion, automation orchestration, provider opt-in/consent management, audit logs, and integration testing before using with real customers.
